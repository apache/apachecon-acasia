Data Storage & Computing

Track Chairs
Gang Li Nicholas Jiang
Sessions
14
Room
Mtn WanShou Hall

Big data is an important branch of computer science,Researches and innovations in the big data storage and computing have never stopped. Big Data is leading and changing various industries and is inseparable from our lives.

Big Data is also a very important part of ASF. ASF has so many big data storage and computing projects, such as Apache Hadoop, Apache Spark, Apache HBase, Apache Ozone, Apache CarbonData, Apache Cassandra, Apache ZooKeeper, Apache Celeborn etc.

In this topic, you will learn the cutting-edge trends of these technologies and the practical experience, principles, architecture analysis and other exciting content from first-line users.
