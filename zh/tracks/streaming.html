流处理

出品人
李钰 王鑫
议题
11
会场
圆明厅

流式数据处理是当今大数据领域的趋势，很多企业渴望更及时地洞察自己的数据，而曾经的“批处理”思维正迅速被流式处理所取代。越来越多的公司，无论大小，都在重新思考技术架构时把实时性作为第一考量，并开始用强大的开源引擎如Apache Flink, Apache Spark, Apache Kafka, Apache Pulsar, Apache Storm, Apache StreamPark, Apache Paimon 等构建自己的实时计算平台。

在该主题中，您将了解到一线大厂把这些Apache项目应用到其生产环境中的实际经验，以及这些Apache项目生态的最新发展和流计算技术未来的发展方向。
